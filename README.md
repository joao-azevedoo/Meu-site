**Aluno:** João Vitor de Azevedo  
**Disciplina:** Programação para Web 1 — UTFPR, Campus Dois Vizinhos.

## Objetivo

Desenvolver um site pessoal de forma incremental, começando pela estrutura semântica em HTML puro, depois acrescentando CSS externo e layout responsivo Mobile First.

## Etapa atual

A pasta `01-html-puro` contém a primeira versão, sem CSS, JavaScript ou frameworks. Inclui apresentação, fotografia, navegação interna, formação, experiências, habilidades, perfis, contato por e-mail e formulário demonstrativo sem envio.

## Executar

Abra `01-html-puro/index.html` no navegador. Mantenha a pasta `imagens` junto do HTML.
