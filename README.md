**Aluno:** João Vitor de Azevedo  
**Disciplina:** Programação para Web 1 — UTFPR, Campus Dois Vizinhos.

## Objetivo

Desenvolver um site pessoal de forma incremental, começando pela estrutura semântica em HTML puro, depois acrescentando CSS externo e layout responsivo Mobile First.

## Etapas do projeto

### Etapa 1 — HTML puro

A pasta `01-html-puro` contém a primeira versão do site, desenvolvida somente com HTML, sem CSS ou JavaScript.

Inclui apresentação pessoal, fotografia, formação acadêmica, experiências profissionais, habilidades, links para perfis profissionais, navegação interna e formulário de contato demonstrativo.

### Etapa 2 — CSS externo

A pasta `02-css` contém a segunda versão do site, com estilização visual utilizando um arquivo CSS externo (`estilos.css`).

Foram adicionados cores, tipografia, espaçamentos, bordas, organização visual das seções, estilização de links e formulário, além de efeitos `hover`.

### Etapa 3 — Mobile First

Etapa futura destinada à implementação de um layout responsivo para celulares, tablets e computadores.

## Executar

Para executar localmente, abra o arquivo `index.html` da etapa desejada no navegador, mantendo os arquivos CSS e imagens em suas respectivas pastas.
