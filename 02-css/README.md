# Etapa 2 — Site pessoal com CSS

**Aluno:** João Vitor de Azevedo

**Disciplina:** Programação para Web 1 — UTFPR

## Objetivo

Estilizar o site pessoal desenvolvido na primeira etapa, utilizando CSS externo para separar a estrutura HTML da apresentação visual.

## Tecnologias utilizadas

- HTML5
- CSS3

## Recursos implementados

- Arquivo CSS externo (`estilos.css`)
- Paleta de cores em preto e cinza
- Personalização de fontes e tamanhos
- Espaçamentos e bordas
- Organização visual das seções
- Estilização dos links e formulário
- Efeitos hover nos links de navegação

## Publicação

Link do site: pendente de publicação no GitHub Pages.

## Execução

Abra o arquivo `index.html` no navegador, mantendo o arquivo `estilos.css` e a pasta `imagens` no mesmo diretório.
